# SM_RopeCoil

686 üçgen; altı görünür sarım, çap ~0.44 m, halat kalınlığı 0.030 m; demet derinliği ~0.113 m. İç sarımdan alt-sağ siluetin dışına kıvrılan kısa uç rijit gövdeye bağlıdır. Pivot merkez; Grip_L/R x=±0.204 m.

Dolap: **SM_TowTruck_LockerDoor_L1**, taban 0.455 m. Bölüm 1 yerleşiminde çekici +90° Z dönük, yerel +X yol/dağ tarafına (+Y) bakar. L1 tabanı L2 teker üstü dolabından alçaktır ve 1.2 m erişim sınırını sağlar. Kangal kök-yerel (1.10, -0.100, 1.08) m, XYZ Euler (0,0,90)°; dolap içinde dik ve askıda. L1 kapağı (0,0,-1) ekseninde 90° açılır. Kamyon yeniden yönlendirilirse yol tarafını oyun kodu yeniden değerlendirmelidir.

Unity: Scale Factor 1, Convert Units açık, Bake Axis Conversion kapalı. Grip noktaları el IK hedefidir. Kangal rijit prop olarak karaktere bağlanır; klip FBX’inde mesh bulunmaz.
